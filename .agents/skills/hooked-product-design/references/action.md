# Action: make the useful next step easier

Book basis: chapter 3. Instrumentation, accessibility, and implementation checks are practical extensions.

## Motivation, ability, trigger

The book presents Fogg's **B = MAT**: sufficient motivation and ability coincide with a trigger. This is a conceptual model, not numeric multiplication or a prediction engine. Historical terminology is preserved; do not present it as the wording of every later Fogg publication.

Choose the smallest behavior leading to the anticipated reward. Count decisions, waits, typing, navigation, and recovery, not only taps. Login is an intermediate step unless account access is the actual reward. Distinguish this action from future-value investment.

If relevant cue and motivation exist, increase ability first. More explanation rarely fixes cumbersome interaction. If motivation is missing, investigate the benefit and audience.

## Six simplicity constraints

| Constraint      | Question                                  | Possible change                                |
| --------------- | ----------------------------------------- | ---------------------------------------------- |
| Time            | Too long for this moment?                 | Short useful unit, continuation, less waiting  |
| Money           | Does cost block participation?            | Honest cost/value, viable affordable option    |
| Physical effort | Awkward or demanding interaction?         | Appropriate input, reachable controls          |
| Brain cycles    | Interpretation/memory/calculation burden? | Clear labels, visible context, fewer decisions |
| Social deviance | Inappropriate or exposing in context?     | Privacy, quiet interaction, audience controls  |
| Non-routine     | Disruption of a familiar pattern?         | Familiar conventions, gradual introduction     |

Optimize the user's scarce resource in context. A typing shortcut may create privacy concerns; audio may help at home but fail on a quiet train.

## Four heuristics, applied truthfully

**Scarcity:** real capacity can matter; verify availability/expiry. Do not invent stock limits or countdowns for unlimited digital goods.

**Framing:** describe value in the user's context without hiding cost, exclusions, or risk. Framing is not guaranteed to improve experience.

**Anchoring:** compare actual costs or observed personal baselines. Avoid invented original prices and distorted reference points.

**Endowed progress:** acknowledge genuine work, including imported/initial work where applicable. Make remaining effort clear. Arbitrary completion bars should not imply personal inadequacy.

These are the chapter's four heuristics, not all behavioral science. Choose one only when it addresses the actual decision; assess comprehension and useful outcome alongside conversion.

## Motivation and handoff

The book groups motivation as pleasure/pain, hope/fear, acceptance/rejection. Clarify evidenced benefits; do not default to fear, shame, or exclusion.

Specify before/after flow, removed friction, necessary disclosures, loading/error/empty states, accessible interactions, and proposed labels. A shorter happy path with broken recovery is not a completed improvement.
