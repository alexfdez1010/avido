# Internationalization

Supported languages: **Spanish (Spain, `es-ES`)** and **English (`en-US`)**. The language is detected once at startup from the device locale with `expo-localization`; any non-Spanish locale falls back to English.

All code, comments and documentation are in English. Spanish appears only in user-facing strings.

## Helpers (`src/i18n/index.ts`)

```ts
tx('Libro terminado', 'Book finished');          // pick by language
plural(n, ['libro', 'libros'], ['book', 'books']);
fmtNum(1234);                                     // locale-aware number
LOCALE;                                           // 'es-ES' | 'en-US' for Intl/Date APIs
```

Arguments are always `(spanish, english)`.

## Guidelines

- Every visible string, notification and error shown to the user must go through `tx`/`plural`.
- Use `LOCALE` for dates and numbers; never hard-code formats.
- Achievements keep Spanish titles inline with an English map keyed by the persisted achievement ID (`src/game/achievements.ts`).
